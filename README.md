# TaskHub CLI

Консольний застосунок на Python для керування списком завдань.
Працює через командний рядок, дані зберігаються у файлі `tasks.json`.

## Можливості

- додавання, перегляд, редагування та видалення завдань
- позначення завдань виконаними
- пошук, сортування, статистика
- експорт у TXT та імпорт з TXT
- перевірка введення (порожній текст, неіснуючий номер)

## Структура проєкту

| Файл | Призначення |
|---|---|
| `taskhub.py` | точка входу, запуск програми |
| `cli.py` | командний рядок (`argparse`), виведення результатів |
| `core.py` | уся логіка роботи із завданнями |
| `storage.py` | читання та запис JSON-файлу |

## Запуск

Потрібен Python 3. Сторонні бібліотеки не потрібні.

```
python taskhub.py <команда> [аргументи]
python taskhub.py -h
```

## Команди

| Команда | Опис |
|---|---|
| `add "текст"` | додати завдання |
| `show` | показати всі завдання |
| `show --done` | лише виконані |
| `show --todo` | лише невиконані |
| `edit <номер> "текст"` | змінити текст завдання |
| `done <номер>` | позначити виконаним |
| `undone <номер>` | зняти позначку виконання |
| `delete <номер>` | видалити завдання |
| `search <текст>` | пошук за текстом |
| `stats` | статистика (усього, виконано, залишилось) |
| `sort` | показати за алфавітом |
| `count` | кількість завдань |
| `first` | перше завдання |
| `last` | останнє завдання |
| `doneall` | позначити всі виконаними |
| `clear` | видалити всі виконані |
| `reset` | видалити всі завдання |
| `export [файл]` | зберегти список у TXT (за замовчуванням `tasks.txt`) |
| `import <файл>` | завантажити завдання з TXT (рядок = завдання) |

## Приклад

```
> python taskhub.py add "Купити молоко"
Додано завдання #1: Купити молоко

> python taskhub.py show
  1. [ ] Купити молоко

> python taskhub.py done 1
Завдання #1 виконано.

> python taskhub.py add ""
Помилка: текст завдання не може бути порожнім.
```

## Формат даних

Завдання зберігаються у `tasks.json`:

```json
[
  {
    "id": 1,
    "text": "Купити молоко",
    "done": false
  }
]
```
